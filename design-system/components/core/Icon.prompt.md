Renders a Lucide glyph in the brand's icon style (2px stroke, 24px grid) tinted with currentColor.

```jsx
<Icon name="map-pin" size={20} />
<Icon name="arrow-right" size={16} style={{ color: 'var(--blue-500)' }} />
```

Lucide is the only icon set in the brand. Never mix in emoji or another set. Icons are decorative support for a label — never used alone as a control except in the socials row.
