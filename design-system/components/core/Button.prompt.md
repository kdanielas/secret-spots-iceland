The brand's only button. Amber `primary` is reserved for the booking CTA — one per screen region; pair it with `outline` or `outlineLight` for the secondary action.

```jsx
<Button variant="primary">Check Availability</Button>
<Button variant="outlineLight">Explore Iceland Photography Tours</Button>
<Button variant="dark" fullWidth>Check Availability</Button>
<Button variant="link" iconAfter="arrow-right">Learn how it works</Button>
```

Always fully rounded (`--radius-pill`). Labels are Title Case sentence fragments, never shouty — except `link`, which is uppercase and tracked.
